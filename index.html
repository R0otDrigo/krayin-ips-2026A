Herramientas Utilizadas

El ecosistema GitHub como columna vertebral del proceso Scrum + DevOps del proyecto.

📋
GitHub Projects
Tablero Kanban para gestionar el Product Backlog, armar Sprints y asignar historias de usuario. Visualización del progreso en tiempo real.
⚙️
GitHub Actions
Automatización CI/CD. Compila el código, corre las pruebas, detecta errores y despliega la app a staging automáticamente.
🌐
GitHub Pages
Publica el entorno de staging, la documentación técnica del proyecto y el Burndown Chart generado por GitHub Actions.
🎫
GitHub Issues
Registra las historias de usuario del Product Backlog, reporta bugs en testing y documenta decisiones técnicas del sprint.
📖
GitHub Wiki
Documentación técnica centralizada del proyecto, arquitectura, decisiones de diseño y guías de implementación.
🐳
Docker Compose
Infraestructura DevOps adaptable para facilitar la configuración del pipeline y el entorno de desarrollo reproducible.
